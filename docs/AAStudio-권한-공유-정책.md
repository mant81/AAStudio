# AAStudio 권한 공유 정책

## 1. 목적

AAStudio에서 내부 사용, 외부 readonly 공개, 파일 다운로드 허용을 어떤 기준으로 처리할지 정의한다.

## 2. 기본 원칙

- 내부 사용자는 전체 기능을 사용한다.
- 외부 공개는 readonly로만 허용한다.
- 외부 사용자는 파일을 다운로드할 수 있다.
- 외부 사용자는 수정, 업로드, 삭제를 할 수 없다.

## 3. 권한 등급

### 3.1 Owner

- 프로젝트 생성
- 편집
- 삭제
- 업로드
- 공유 설정

### 3.2 Editor

- 편집
- 업로드
- 내부 협업

### 3.3 Readonly

- 열람
- 파일 다운로드
- 검색

### 3.4 Guest

- 제한된 열람
- 다운로드 여부는 별도 정책으로 제어

## 4. 공유 범위

- Wiki 문서
- 다이어그램
- API 명세
- 파일 첨부
- WBS 열람

## 5. 차단 범위

- Wiki 수정
- 파일 업로드
- 파일 삭제
- DB 모델 직접 수정
- 공유 설정 변경

## 6. 로그 정책

- 열람 로그를 남긴다.
- 다운로드 로그를 남긴다.
- 공유 설정 변경 로그를 남긴다.

## 7. 다음 단계

이 정책을 기준으로 실제 화면에서 readonly 상태를 어떻게 표시할지 정하면 된다.
