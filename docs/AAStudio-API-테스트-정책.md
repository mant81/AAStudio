# AAStudio API 테스트 정책

## 1. 목적

AAStudio의 API 명세는 문서화에 그치지 않고 실제 백엔드 호출 테스트를 수행할 수 있어야 한다.

## 2. 기본 원칙

- 실제 백엔드 엔드포인트로 호출한다.
- 공통 인증을 지정할 수 있어야 한다.
- 샘플 데이터가 DB에 유지되어야 한다.
- 테스트 결과를 저장하고 재사용할 수 있어야 한다.
- 테스트 화면에서 실행과 확인을 함께 처리한다.

## 3. 테스트 항목

- HTTP method
- path
- query parameter
- body payload
- headers
- auth context
- response status
- response body
- error response

## 4. 공통 인증

- 프로젝트별 기본 인증 프로필을 지정한다.
- 테스트 케이스는 기본 인증 프로필을 상속할 수 있다.
- 필요 시 개별 테스트 케이스에서 인증을 덮어쓸 수 있다.

## 5. 샘플 데이터

- 샘플 데이터는 프로젝트 DB에 유지한다.
- 샘플 데이터셋은 재사용할 수 있어야 한다.
- 테스트는 샘플 데이터를 참조할 수 있어야 한다.

## 6. 결과 저장

- 실행 요청
- 응답 스냅샷
- 상태 코드
- 성공/실패 판정
- 실행 시각
- 메시지
