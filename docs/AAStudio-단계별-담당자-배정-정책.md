# AAStudio 단계별 담당자 배정 정책

## 1. 목적

프로젝트의 각 개발 단계에 담당자를 어떻게 배정하고 관리할지 정의한다.

## 2. 기본 원칙

- 한 단계에는 최소 1명의 담당자가 있어야 한다.
- 단계별 보조 담당자를 둘 수 있다.
- 담당자 정보는 프로젝트별로 저장한다.
- 담당자 변경 이력은 남겨야 한다.

## 3. 담당자 정보

- 담당자명
- 직급
- 담당자 연락처
- 담당자 이메일
- 역할

## 4. 단계 예시

- 기획
- 분석
- 설계
- 구현
- 검토
- 배포 준비
- 완료

## 5. 배정 규칙

- 각 단계에는 기본 담당자를 배정한다.
- 필요 시 보조 담당자를 추가한다.
- 담당자는 중복 배정될 수 있으나 현재 책임 단계는 구분되어야 한다.
- 담당자 변경 시 변경 메모를 남긴다.

## 6. 상태 관리

- 대기
- 진행
- 검토
- 보류
- 완료

## 7. 변경 이력

- 담당자 변경
- 단계 변경
- 상태 변경
- 관련 산출물 연결 변경

## 8. 다음 단계

이 정책을 기준으로 프로젝트 대시보드 화면과 SQLite 저장 구조가 연동된다.
