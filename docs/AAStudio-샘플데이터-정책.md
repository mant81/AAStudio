# AAStudio 샘플 데이터 정책

## 1. 목적

AAStudio에서 API 테스트와 문서 검증에 사용할 샘플 데이터를 어떻게 유지할지 정의한다.

## 2. 기본 원칙

- 샘플 데이터는 프로젝트 단위로 유지한다.
- 샘플 데이터는 DB에 보존한다.
- 샘플 데이터는 재사용 가능해야 한다.
- 테스트 실행 시 샘플 데이터셋을 선택할 수 있어야 한다.

## 3. 샘플 데이터 구성

- 데이터셋 이름
- 설명
- 공유 여부
- 항목 키
- 항목 값
- 생성 시각

## 4. 사용 방식

- API 테스트에서 참조
- 문서 예제에서 참조
- DB 모델 검토에서 참조
- 위키 설명에서 참조

## 5. 관리 방식

- 샘플 데이터는 프로젝트별로 분리한다.
- 필요 시 읽기 전용으로 공유할 수 있다.
- 삭제 대신 비활성화 정책을 둘 수 있다.

## 6. 다음 단계

이 정책을 기준으로 API 테스트 화면과 DB 저장 구조가 연결된다.
