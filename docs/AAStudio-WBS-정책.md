# AAStudio WBS 정책

## 1. 목적

AAStudio에서 WBS를 어떤 방식으로 등록하고 연결할지 정의한다.

## 2. 기본 원칙

- WBS는 업무를 쪼개어 관리하는 구조다.
- 초반에는 등록과 계층화에 집중한다.
- 담당자 배정, 일정 관리, 진척률 관리는 후순위다.

## 3. 등록 항목

- 업무명
- 설명
- 상위 업무
- 우선순위
- 연결 산출물
- 상태
- 메모

## 4. 연결 대상

- Wiki 페이지
- DB 모델
- 다이어그램
- API 명세
- 보안점검 항목
- 소스코드 점검 결과
- 파일 첨부

## 5. 상태 예시

- 대기
- 진행
- 검토
- 완료
- 보류

## 6. 운영 방식

- 업무는 계층 구조로 쌓는다.
- 산출물은 WBS와 연결한다.
- 완료된 업무는 관련 문서 버전과 함께 추적한다.

## 7. 다음 단계

이 정책을 기준으로 WBS 화면과 위키 화면에서 연결 동작을 구체화하면 된다.
