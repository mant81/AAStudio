# 테이블 설정 연결 표시와 헤더 색상 미리보기

## 목적
- 설정 레이어가 어느 테이블에 연결되는지 화살표로 보여주고, 선택한 헤더 색상을 즉시 확인한다.

## 분석 및 수용 기준
- 레이어 방향에 맞춰 화살표가 설정을 연 테이블을 가리킨다.
- 팔레트·사용자 색상 선택 시 해당 테이블 헤더만 바뀌며 취소 시 원래 색으로 돌아간다.

## 변경 파일
- `db-modeling.html`, `app.css`: 레이어 화살표 추가.
- `db-modeling.js`: 화살표 위치 및 헤더 색상 미리보기·취소 처리.
- `fragments/layout.html`: CSS/JS 캐시 버전 갱신.

## 검증
- `node --check src/main/resources/static/js/db-modeling.js`: 통과.
- 브라우저 시각 검증은 수행하지 않았다.

## 미해결 이슈와 다음 작업
- 실제 화면에서 화살표 위치와 오른쪽 공간 부족 시 왼쪽 표시를 확인한다.
