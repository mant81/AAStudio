# 샘플 목록 UI 정리

## 목적
- 샘플 목록의 카드형 외곽선이 다이어그램 화면의 평평한 패널 스타일과 어울리지 않는 문제를 개선한다.

## 변경 사항
- 샘플 카테고리의 `rounded-xl border ...` 외곽 카드 스타일을 제거했다.
- 샘플 패널의 `space-y-2` 간격을 제거해 카테고리 목록이 끊기지 않고 이어지도록 했다.
- 카테고리는 얇은 하단 구분선으로 나누고, 펼침 헤더와 샘플 행에만 은은한 hover 배경을 적용했다.
- DB 모델링 화면의 트리 목록을 기준으로 카테고리 아이콘·항목 개수·들여쓰기·하위 행 아이콘을 적용했다.
- 카테고리 제목과 하위 항목의 키워드에 맞춰 개발·클라우드·DB·보안·모니터링 및 세부 기능 아이콘을 개별 매핑했다.
- 샘플 행의 들여쓰기와 간격을 조정해 아코디언 계층을 명확히 했다.
