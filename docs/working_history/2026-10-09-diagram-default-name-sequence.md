# 다이어그램 기본 이름 순번 보정

## 변경 내용

- 새 다이어그램에 이름을 입력하지 않으면 기존 `다이어그램 숫자` 이름 중 가장 큰 숫자에 1을 더한 이름을 사용한다.
- 다이어그램 추가 창을 열 때도 다음 기본 이름을 입력창에 미리 표시한다.
- 다이어그램을 삭제하거나 사용자 지정 이름을 사용해도 기본 이름이 중복되지 않도록 했다.
- 직접 입력한 다이어그램 이름은 그대로 보존한다.

- `node --check src/main/resources/static/js/diagram.js`
