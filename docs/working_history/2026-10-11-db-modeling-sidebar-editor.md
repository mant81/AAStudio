# DB 모델링 사이드바 에디터 개선

## 변경 내용

- `db-modeling-workspace`의 ERD 캔버스가 에디터 모드에서도 항상 표시되도록 수정했다.
- 기존 보조 사이드바 영역을 VS Code 스타일의 스키마 에디터로 전환했다.
- GUI 모드에서는 기존 객체 탐색기를 표시하고, 에디터 모드에서는 스키마 입력 영역을 표시한다.
- 기존 스키마 입력 textarea를 재사용해 입력 데이터와 GUI 생성 동작의 연결을 유지했다.
- 좌측 에디터를 dbdiagram.io와 유사한 넓은 코드 패널로 조정하고 파일 탭, 줄 번호, 다크 테마를 추가했다.
- 에디터와 ERD 영역이 부모 작업 영역의 전체 높이를 사용하도록 높이 제약을 보강했다.
- 페이지 루트와 중간 flex 컨테이너에도 `height: 100%` 및 `min-height: 0`을 연결해 실제 뷰포트 높이를 상속하도록 수정했다.
- `secondary-sidebar` 우측 경계에 `col-resize` 핸들을 추가해 드래그로 폭을 조절하고 마지막 폭을 저장하도록 했다.
- 리사이즈를 사용하지 않은 초기 상태는 기존 `w-64`(`16rem`) 기본 폭을 유지하도록 조정했다.
- 에디터 모드 진입 시 `collapsed`와 `w-14`를 함께 해제해 사이드바가 축소 폭으로 되돌아가 겹치는 문제를 방지했다.
- CSS 폭 유틸리티보다 리사이즈 전용 폭이 우선하도록 고정해 에디터가 세로로 눌리거나 ERD와 겹치지 않도록 보강했다.
- 좌측 패널과 ERD 사이 경계 내부에 리사이즈 핸들을 배치해 workspace에 가려지지 않고 좌우 폭을 조절하도록 수정했다.
- JavaScript 캐시 버전을 갱신했다.
