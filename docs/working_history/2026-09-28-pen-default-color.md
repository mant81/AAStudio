# 펜 옵션 기본 색상 변경

## 변경 사항

- 펜 옵션의 첫 번째 색상과 기본 색상 입력값을 빨간색(`#FF0000`)으로 변경했다.
- JavaScript의 신규 펜 기본 상태도 동일한 색상으로 맞췄다.

## 검증

- 템플릿과 JavaScript에서 기존 펜 기본 색상(`#7C839B`)의 사용 여부를 검색해 제거된 것을 확인했다.
- `node --check src/main/resources/static/js/diagram.js` 통과.

## 추가 변경: 펜 모드 선택 차단

- 펜 또는 지우개 모드에서는 노드·도형·선 선택 함수가 실행되지 않도록 최종 방어 조건을 추가했다.
- 펜 모드 진입 시 기존 선택을 해제하는 동작을 유지했다.

## 추가 변경: 지우개 크기 옵션 확대

- 지우개 프리셋을 `16/32/48px`로 확대하고 기본값을 `32px`로 변경했다.
- 지우개 슬라이더 범위를 `8~48px`로 변경했다.
- 지우개 커서 표시의 최대 크기도 `48px`에 맞췄다.

## 추가 변경: 지우개 옵션 UI 단순화

- 원형 크기 프리셋과 미리보기 UI를 제거하고, 슬라이더와 현재 크기 표시만 남겼다.

## 추가 변경: 지우개 모드 커서 고정

- 지우개 모드에서 노드와 선 위에 마우스를 올려도 `move` 커서가 표시되지 않고 지우개 커서가 유지되도록 했다.
- 지우개 모드에서는 선 핸들과 노드 리사이즈·회전 핸들도 비활성화했다.
- 그룹 박스를 포함한 모든 노드와 선의 포인터 이벤트를 펜 모드와 동일하게 통과시켜 `move` hover가 나타나지 않도록 했다.

## 추가 변경: 선택 모드 선 이동

- 선택 모드에서 자유롭게 그린 펜 선도 선택 후 드래그하여 이동할 수 있도록 했다.
- 연결선의 기존 선택·이동 동작은 유지했다.

## 추가 변경: 이미지 Blob 첨부

- 툴바의 이미지 버튼이 파일 선택 창을 열도록 변경했다.
- 선택한 이미지 Blob을 Data URL로 저장해 이미지 노드로 다이어그램 중앙에 첨부한다.
- 이미지 데이터와 파일명을 노드 속성으로 보존해 저장·복원 시에도 이미지를 유지한다.
- `node --check src/main/resources/static/js/diagram.js` 통과.

## 추가 변경: 지우개 사용 중 펜 선 이동 방지

- 지우개가 펜 경로를 새 조각으로 재생성하지 않고 기존 경로 좌표를 유지하도록 변경했다.
- 지워진 구간은 경로의 표시 구간만 숨겨, 반복 지우기 중 선이 미세하게 이동하는 문제를 방지했다.
- `node --check src/main/resources/static/js/diagram.js` 통과.
- `mvn test`는 Maven(`mvn`)이 설치되어 있지 않아 실행할 수 없었다.

## 미해결 이슈

- 없음.

## 추가 변경: 펜 지우개

- 펜 지우개가 자유 손그림 선 전체를 삭제하지 않고, 지우개 원과 겹치는 구간만 잘라내도록 변경했다.
- 지우개를 드래그하는 동안에도 겹치는 구간을 연속해서 지울 수 있도록 했다.
- 연결선 등 자유 손그림이 아닌 선의 기존 삭제 동작은 유지했다.
- `node --check src/main/resources/static/js/diagram.js` 통과.
