# 컬럼 편집 표 항목 정리

- 컬럼 편집 모달을 표 형태로 정리하고 `컬럼명`, `#`, `Data type`, `Not Null`, `Default`, `Comment`만 표시하도록 변경했다.
- 사용하지 않는 `Identity`, `Collation` 입력과 관련 레이아웃을 제거했다.
- 모달 폭을 넓히고 표 영역에 최대 높이와 스크롤을 적용해 `Comment` 입력을 항상 확인할 수 있게 했다.
- 편집 행의 인덱스와 저장 대상 선택자를 수정해 컬럼 수정 모달이 정상적으로 열리고 저장되도록 보완했다.
- 표 영역에 세로 스크롤을 항상 표시하고, 각 컬럼에 위·아래 순서 변경 버튼을 추가했다.
- 표 헤더를 sticky로 고정해 세로 스크롤 중에도 항목명이 유지되도록 했다.
- 스크롤바 트랙과 thumb 스타일을 추가하고, 첫 행의 위로 이동 및 마지막 행의 아래로 이동 버튼을 비활성화했다.
- 동적 컬럼 입력에 고유한 `id`와 `name`을 부여해 브라우저 폼 접근성 경고를 제거했다.
- 컬럼 추가·삭제 버튼을 추가하고 저장 시 DBML/DDL 원문, 에디터, 캔버스가 함께 갱신되도록 연결했다.
- 순서 조작과 삭제를 별도 컬럼으로 분리했다.
- 모달 헤더를 제목·테이블명·닫기 영역으로 분리하고 영역 경계를 추가했다.
- 선택 테이블명 표시를 컬럼 목록 작업 영역으로 이동했다.
- 모달을 세로 flex 구조로 조정해 저장·취소 footer가 항상 보이고 표 영역만 스크롤되도록 했다.
- 확인: `node --check src/main/resources/static/js/db-modeling.js`, `git diff --check`
