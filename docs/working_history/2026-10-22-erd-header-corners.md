# ERD 테이블 헤더 모서리 여백 수정

## 목적
- 테이블 헤더 좌우 상단의 흰 배경 틈을 없앤다.

## 분석 및 수용 기준
- 테이블 바깥 배경과 헤더에 같은 색상을 적용하고, 컬럼 영역만 흰색으로 채운다.
- 설정에서 색상 미리보기와 취소 시 바깥 모서리까지 함께 바뀐다.

## 변경 파일
- `db-modeling.js`: 색상 변수를 테이블 요소에 적용하고 미리보기·취소 경로 갱신.
- `app.css`: 테이블 바깥 배경과 컬럼 영역 배경 조정.
- `fragments/layout.html`: CSS/JS 캐시 버전 갱신.

## 검증
- `node --check src/main/resources/static/js/db-modeling.js`: 통과.
- `git diff --check`: 통과(기존 줄바꿈 경고만 출력).

## 미해결 이슈와 다음 작업
- 브라우저에서 상단 모서리 색상을 확인한다.
