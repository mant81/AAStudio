# 다이어그램 이름 변경·삭제 위치 결정

## 목적

다이어그램 선택 목록(`diagram-current-name`)의 책임을 명확히 하고, 이름 변경·삭제 기능의 위치를 결정한다.

## 결정 사항

- `/diagram`의 `diagram-current-name` 목록은 다이어그램 선택 기능만 제공한다.
- 다이어그램 이름 변경 및 삭제는 `/diagram` 헤더에서 `Share` 오른쪽에 배치하는 설정 아이콘 메뉴에서 처리한다.
- 선택 목록에 수정·삭제 액션을 추가하지 않아 작업 중 실수로 구조를 변경하지 않도록 한다.

## 현재 구현과 후속 작업

- 현재 다이어그램 목록은 `diagram.html`과 `diagram.js`에서 화면 상태로 관리된다.
- `/diagram` 헤더에는 현재 Import, Export, Share 액션이 있으며 설정 아이콘을 추가할 수 있다.
- 실제 이름 변경·삭제를 구현할 때는 Diagram 화면과 관리 메뉴가 같은 다이어그램 목록을 사용하도록 저장 모델/API를 먼저 정리한다.

## 구현 내용

- Share 오른쪽에 다이어그램 관리 설정 아이콘과 메뉴를 추가했다.
- 이름 변경은 기존 다이어그램 이름 모달을 재사용한다.
- 관리 메뉴에서 내보내기 형식 선택과 JSON 직접 내보내기를 제공한다.
- 관리 메뉴는 현재 다이어그램 설정 전용으로 유지한다.
- 설정 메뉴에 `백업하기`와 `복원하기`를 제공한다.
- 설정 메뉴의 `내보내기 형식 선택` 항목은 제거한다.
- 상단 `Import` 버튼을 제거하고 JSON 복원 진입점을 설정 메뉴의 `복원하기`로 통합한다.
- 설정 메뉴의 `백업하기`에서 JSON 구조를 내보내고, 상단 `Export` 메뉴의 JSON 항목은 제거한다.
- `백업하기` 파일명은 `제목_yyyymmddhhss.json` 형식으로 생성한다.
- 삭제 전 확인을 표시하고, 삭제 후 인접 다이어그램을 선택한다.
- 마지막 다이어그램은 삭제할 수 없도록 처리한다.

## 검증

- 기존 구현 확인: 선택 목록은 선택 및 추가 기능만 제공하며 이름 변경·삭제 핸들러는 없다.
