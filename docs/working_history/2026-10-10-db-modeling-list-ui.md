# DB 모델링 오브젝트 목록 UI 정리

## 목적
- `/db-modeling`의 `space-y-1` 기반 그룹 간격과 둥근 행 스타일이 샘플 목록과 다른 카드형 인상을 주는 문제를 개선한다.

## 변경 사항
- 최상위 그룹 간격을 얇은 구분선 방식으로 변경했다.
- `/diagram` 샘플 목록과 동일하게 그룹 헤더, 하위 목록의 여백과 hover 색상을 맞췄다.
- 카드처럼 보이던 하위 행의 외곽선과 좌측 강조선을 제거하고 선택·hover 상태만 행 배경으로 표현했다.

## 검증
- 템플릿 클래스 변경 범위 확인
- `git diff --check`
