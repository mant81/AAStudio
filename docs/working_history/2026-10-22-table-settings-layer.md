# 테이블 설정 레이어 배치

## 목적
- 테이블 설정을 중앙 모달 대신 선택한 캔버스 테이블 오른쪽에 표시한다.

## 분석 및 수용 기준
- 설정 클릭 시 테이블 옆에 레이어가 열린다.
- 오른쪽 공간이 부족하면 왼쪽에 표시하고, 화면 높이를 벗어나지 않는다.

## 변경 파일
- `db-modeling.html`: 설정창을 독립 레이어로 전환.
- `app.css`: 레이어와 카드의 위치·크기 정의.
- `db-modeling.js`: 클릭한 테이블 기준 위치 계산 및 바깥 클릭·크기 변경 시 닫기.
- `fragments/layout.html`: CSS/JS 캐시 버전 갱신.

## 검증
- `node --check src/main/resources/static/js/db-modeling.js`: 통과.
- `git diff --check`: 통과(기존 줄바꿈 경고만 출력).
