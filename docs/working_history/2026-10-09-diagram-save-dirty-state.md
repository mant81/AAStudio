# 다이어그램 저장 상태 오표시 수정

## 원인

캔버스 클릭으로 선택 프레임, 선택 CSS 클래스, 연결선 핸들 등 편집 UI가 바뀌면 MutationObserver가 이를 다이어그램 데이터 변경으로 오인했다.

## 변경 내용

- 저장 감시 시 선택 상태와 편집 UI 전용 요소를 비교에서 제외했다.
- 노드·연결선·속성·위치 등 실제 다이어그램 상태가 달라질 때만 `변경됨`을 표시한다.
- 저장된 상태를 불러온 직후에는 현재 상태를 기준선으로 설정해 불필요한 재저장을 막았다.
- 이름 변경처럼 데이터 본문 비교에 포함되지 않는 명시적 저장 요청은 강제로 처리한다.
