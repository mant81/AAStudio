# 테이블 더블클릭 설정창 수정

## 목적
- 캔버스 테이블 더블클릭으로 컬럼 수정 레이어를 연다.

## 분석 및 수용 기준
- 기존 테이블 드래그의 pointerdown이 더블클릭을 가로막지 않아야 한다.
- 더블클릭 이벤트가 설정 버튼과 같은 설정 레이어 초기화 경로를 호출해야 한다.

## 변경 파일
- `db-modeling.js`: 캡처 단계 더블클릭 처리와 다중 클릭 드래그 방지.
- `fragments/layout.html`: JS 캐시 버전 갱신.

## 검증
- `node --check src/main/resources/static/js/db-modeling.js`: 통과.
- `git diff --check`: 통과(기존 줄바꿈 경고만 출력).

## 미해결 이슈와 다음 작업
- 브라우저에서 테이블 본문과 헤더의 더블클릭을 확인한다.
