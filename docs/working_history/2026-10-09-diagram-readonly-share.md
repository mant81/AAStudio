# 다이어그램 읽기 전용 링크 공유

## 목적

현재 다이어그램을 링크로 공유하고, 링크 접속자는 편집할 수 없도록 한다.

## 변경 내용

- `링크 공유` 버튼이 현재 다이어그램 상태를 서버에 저장하고 10자리 토큰 URL을 클립보드로 복사한다.
- 공유 URL 접속 시 토큰으로 서버에서 JSON 상태를 조회해 복원한다.
- `링크 공유` 클릭 후 URL을 드롭다운 입력창에 표시한다.
- 입력창에서 URL을 직접 선택할 수 있고, 우측 복사 아이콘으로 클립보드에 복사한다.
- 공유 화면에서는 노드·선 편집, 다이어그램 추가, 관리 메뉴를 비활성화한다.
- 클립보드 사용이 불가능한 환경에서는 링크를 직접 복사할 수 있는 대체 입력을 표시한다.

## 검증

- `node --check src/main/resources/static/js/diagram.js` 통과
- `git diff --check` 통과
