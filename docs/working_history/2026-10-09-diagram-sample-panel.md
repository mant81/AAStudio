# 샘플 다이어그램 선택 패널

## 변경 내용

- 헤더 내보내기 왼쪽에 `샘플 다이어그램` 버튼을 추가했다.
- 우측 속성 패널과 같은 방식으로 샘플 선택 패널을 열고 닫는다.
- 개발, 인프라, 아키텍처, 데이터, 보안, 운영 및 관리 6개 카테고리와 하위 주제를 제공한다.
- 하위 주제를 선택하면 해당 주제에 맞는 노드와 연결선 예시를 현재 캔버스의 별도 영역에 추가한다.
- 기존 캔버스는 유지하고, 추가 결과는 현재 카테고리 상태와 자동 저장 대상으로 반영한다.
