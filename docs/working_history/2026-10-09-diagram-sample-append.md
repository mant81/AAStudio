# 샘플 다이어그램 별도 영역 추가

## 변경 내용

- 샘플 다이어그램의 하위 주제를 선택해도 현재 캔버스 내용을 교체하지 않도록 변경했다.
- 기존 도형이 있으면 그 아래에 샘플 도형과 연결선을 별도 영역으로 추가한다.
- 기존 도형이 없으면 캔버스 상단의 기본 위치에 샘플을 추가한다.
- 카테고리별로 분기형 플로우, 허브 앤 스포크 네트워크, 계층형 아키텍처, 관계형 데이터 구조, 보안 흐름, 운영 피드백 루프 레이아웃을 사용한다.
- 각 샘플의 논리 영역을 그룹상자로 감싸 샘플 내부의 계층과 경계를 시각적으로 구분한다.
- 샘플 추가 시 확인창을 표시하지 않고, 현재 카테고리 상태와 자동 저장 대상으로 반영한다.
