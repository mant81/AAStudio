# AAStudio API 테스트 화면

## 1. 목적

API 명세 탭에서 실제 백엔드 호출 테스트를 실행하고 결과를 확인하는 화면 구성을 정의한다.

## 2. 화면 구성

### 2.1 좌측 패널

- API 그룹 목록
- 테스트 케이스 목록
- 공통 인증 프로필 목록
- 샘플 데이터셋 목록
- 동기화 결과 목록

### 2.2 중앙 작업 영역

- API 명세 상세
- 요청 편집기
- 응답 결과 창
- 테스트 실행 버튼
- 소스코드 동기화 버튼
- 수동 API 추가 버튼
- 테스트 히스토리

### 2.3 우측 속성 패널

- 인증 프로필 설정
- 헤더 설정
- 샘플 데이터 선택
- 기대 상태 코드
- 기대 응답 예제

## 3. 주요 동작

- 실제 백엔드 URL로 호출한다.
- 공통 인증을 자동 적용할 수 있다.
- 샘플 데이터를 선택해 요청을 실행한다.
- 실행 결과를 저장하고 재실행할 수 있다.
- 소스코드 동기화 결과와 수동 추가 항목을 함께 확인할 수 있다.

## 4. 표시 정보

- 요청 스냅샷
- 응답 스냅샷
- 상태 코드
- 성공/실패 여부
- 응답 시간
- 비교 결과

## 5. 다음 단계

이 화면은 공통 인증 정책과 샘플 데이터 관리 정책을 함께 따라야 한다.
