# AAStudio 프로젝트 대시보드 정책

## 1. 목적

AAStudio의 프로젝트별 대시보드는 현재 진행 상황과 담당자 정보를 한눈에 보여주는 운영 화면이다.

## 2. 기본 원칙

- 프로젝트마다 대시보드를 가진다.
- 대시보드는 현재 단계와 담당자 정보를 우선 표시한다.
- 단계별 담당자 정보는 최신 상태를 유지한다.
- 대시보드 정보는 프로젝트 산출물과 연결된다.

## 3. 표시 항목

- 프로젝트명
- 현재 단계
- 단계 상태
- 담당자명
- 직급
- 담당자 연락처
- 담당자 이메일
- 관련 업무
- 관련 산출물
- 최근 변경 내역

## 4. 단계별 배정 규칙

- 한 단계에는 기본 담당자를 둔다.
- 단계별로 보조 담당자를 둘 수 있다.
- 담당자 정보는 이름, 직급, 연락처, 이메일을 포함한다.
- 관련 업무 또는 산출물과 연결되어야 한다.

## 5. 상태 예시

- 대기
- 진행
- 검토
- 보류
- 완료

## 6. 갱신 규칙

- 담당자 변경 시 대시보드가 즉시 갱신된다.
- 단계 변경 시 현재 단계와 상태가 갱신된다.
- 산출물 생성 시 관련 항목이 함께 갱신된다.

## 7. 화면 반영

- 프로젝트 요약 카드에 대시보드 정보를 보여준다.
- 프로젝트 상세 화면에서 단계별 담당자 목록을 보여준다.
- readonly 모드에서는 조회만 가능하다.

## 8. 다음 단계

이 정책을 기준으로 단계별 담당자 저장과 화면 출력 규칙을 더 구체화할 수 있다.
