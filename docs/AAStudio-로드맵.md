# AAStudio 로드맵

## 1. 목적

AAStudio의 문서와 기능을 어떤 순서로 완성할지 정리한다.

## 2. 1단계

- 요약 설계서
- 상세 설계서
- SQLite 테이블 초안
- 화면 구성
- 분석 흐름도
- 단계별 산출물 정책

### 2.1 이번 진행 범위

- 요약 설계서 정리

## 3. 2단계

- 소스코드 점검 정책 구체화
- 보안점검 상세 규칙 정리
- Wiki 버전 정책 정리
- 권한 공유 정책 정리
- 각 단계 최종 산출물 형식 확정
- 프로젝트 대시보드 담당자 정보 구조 확정

## 4. 3단계

- WBS 정책 정리
- API 명세 출력 형식 정리
- 문서 간 참조 정리
- 탭별 최종 산출물 버튼 정의
- 프로젝트 대시보드 화면 항목 고정

## 5. 4단계

- 실제 구현 설계
- 모듈 구조
- 패키징 방식
- 모델 실행 방식

## 6. 완성 기준

- 로컬 PC 전용 구동이 명확해야 한다.
- readonly 공유 정책이 명확해야 한다.
- Wiki와 WBS가 문서로 연결되어야 한다.
- 소스코드 점검과 코드 흐름 기반 보안점검이 분리되어야 한다.
- 각 단계마다 최종 산출물 생성이 가능해야 한다.

## 7. 다음 단계

이 로드맵을 기준으로 실제 개발 설계 문서로 이어갈 수 있다.
