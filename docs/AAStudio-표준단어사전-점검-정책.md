# AAStudio 표준단어사전 점검 정책

## 1. 목적

개발 VO 정의 시 표준단어사전을 적용할 수 있도록, 소스코드에서 VO를 추출하고 단어사전과 비교해 미등록 단어를 식별한다.

## 2. 기본 원칙

- 소스코드 기반으로 VO를 추출한다.
- 표준단어사전은 사전에 등록한다.
- VO와 단어사전을 비교한다.
- 사전에 없는 단어를 추출한다.
- 결과는 점검 리포트와 점검결과 엑셀로 남긴다.

## 3. 점검 흐름

1. 소스코드에서 VO 후보를 추출한다.
2. 표준단어사전을 로드한다.
3. VO와 단어사전을 비교한다.
4. 미등록 단어를 추출한다.
5. 사전 등록 후보와 표기 수정 후보를 제안한다.

## 4. 출력 정보

- VO 이름
- 필드명
- 추출된 표준단어
- 미등록 단어
- 매칭 여부
- 권장 표기
- 수정 메모

## 5. 출력 산출물

### 5.1 점검 리포트

- 읽기용 요약 문서
- 점검 결과 설명
- 미등록 단어 목록
- 권장 표기
- 수정 메모

### 5.2 점검결과 엑셀

- 처리/관리용 산출물
- 항목별 결과 목록
- VO명
- 매칭 여부
- 미등록 단어
- 권장 표기
- 담당자 확인용 데이터

## 6. 운영 방식

- 프로젝트별 표준단어사전을 사용할 수 있어야 한다.
- 단어사전은 버전 관리할 수 있어야 한다.
- 점검 결과는 재실행 가능해야 한다.

## 7. 다음 단계

이 정책은 화면의 메뉴와 분석 흐름에 연결된다.
