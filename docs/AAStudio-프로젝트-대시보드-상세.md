# AAStudio 프로젝트 대시보드 상세

## 1. 목적

프로젝트별 대시보드가 실제 운영에서 어떤 정보를 보여주고 어떤 상호작용을 제공할지 정의한다.

## 2. 핵심 역할

- 현재 프로젝트의 상태를 요약한다.
- 개발 단계별 담당자 정보를 보여준다.
- 단계별 진행 상태를 보여준다.
- 관련 업무와 산출물을 연결해서 보여준다.
- 최근 변경 이력을 보여준다.

## 3. 표시 정보

- 프로젝트명
- 프로젝트 설명
- 현재 단계
- 단계 상태
- 담당자명
- 직급
- 담당자 연락처
- 담당자 이메일
- 관련 업무
- 관련 산출물
- 최근 변경 이력

## 4. 단계별 표시 방식

### 4.1 카드형 요약

- 단계명
- 담당자명
- 상태
- 마지막 갱신 시각

### 4.2 상세 패널

- 직급
- 연락처
- 이메일
- 연결된 업무
- 연결된 산출물
- 변경 메모

## 5. 상호작용

- 단계 카드를 클릭하면 상세 패널이 열린다.
- 담당자를 클릭하면 담당자 연락 정보가 표시된다.
- 산출물을 클릭하면 연결된 Wiki, WBS, 문서로 이동할 수 있다.
- 단계 상태가 바뀌면 대시보드가 즉시 갱신된다.

## 6. 화면 배치

- 프로젝트 목록에서 프로젝트를 선택하면 대시보드가 열린다.
- 대시보드는 메인 화면 상단 또는 중앙 상단에 배치한다.
- 대시보드는 항상 현재 프로젝트와 연결되어 있어야 한다.

## 7. 다음 단계

이 상세 문서를 기준으로 배정 규칙과 상태 이력 규칙을 더 명확히 할 수 있다.
