Auth

POST

/api/v2/users

Create a new user

Creates a new user profile in the system. Requires valid authentication token with administrative privileges. The newly created user will receive an invitation email if `send_invite` is set to true.

Authentication Required Admin Scope

input Request Body

Name
Type
Description
email *
string (email)
User's primary email address. Must be unique across the organization.
first_name *
string
Given name of the user. Max length: 50 chars.
role_id
string (uuid)
UUID of the role to assign. Defaults to standard user if omitted.
metadata
object
Arbitrary JSON key-value pairs for custom attributes. Max 4KB.

code Example Request 

curl -X POST "https://api.aastudio.dev/v2/users" \
  -H "Authorization: Bearer " \
  -H "Content-Type: application/json" \
  -d '{
    "email": "alex.architect@example.com",
    "first_name": "Alex",
    "last_name": "Architect",
    "role_id": "role_8f92a1b",
    "send_invite": true,
    "metadata": {
      "department": "Design",
      "level": "Senior"
    }
  }'
